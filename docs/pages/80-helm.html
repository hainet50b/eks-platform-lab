The image goes to a repository in Amazon ECR. This lab tags images the way docker/metadata-action does. It tags every image with its commit SHA, such as sha-1a2b3c4, and also tags a release image with the Git tag on its commit, such as 0.0.1.

With these tags in place, this lab sets a lifecycle policy on the repository. The policy protects release images from deletion and moves the ones older than the last 10 to the archive storage class, but deletes the other images older than the last 10.

This lab gives developers a workload chart, so that a developer writes only the values for an application. The chart turns them into a Rollout, a Service, an Ingress, an HPA, and a PDB.

The chart sets defaults for Spring Boot. It sends requests to port 8080, and asks Actuator for the health groups liveness and readiness on port 8081. An application on another framework changes the ports and the paths in its values.

Helm renders the chart on your machine. Install Helm, then check it.

The sample is a Spring Boot application, generated with Spring Initializr with two dependencies: Spring Web MVC and Actuator. It answers at / and /pod on the port 8080. Actuator serves its health and its version on the port 8081.

The health has two groups, liveness and readiness, which the probes check later in this part.

The Dockerfile has two stages: a build stage that makes the jar, and a runtime stage that runs it. For container images, Spring Boot has the tools jar mode, which splits the jar into layers. Docker then reuses the unchanged layers, such as the dependencies, when only the code changes.

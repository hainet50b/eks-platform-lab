{{ page_head("Pick a chart version for each workload") }} {% call stage("understand") %} {{ section("idea", "The idea") }}

The platform publishes workload charts to a registry, in versions. Each chart fits one type of workload, such as a Spring Boot application. For each workload, a developer picks the chart and the version. The workload stays on that version until the developer changes it.

The developer changes the version in the same commit as the values, so the values always match the chart that renders them.

{% include "partials/90-chart-registry/versions.html" %} {% endcall %} {% call stage("build") %} {% call step("repository", "Chart repository") %} {% call what() %}

The chart goes to a repository in Amazon ECR, next to the application images. Helm stores a chart in a registry as an OCI artifact, with the version of the chart as its tag.
